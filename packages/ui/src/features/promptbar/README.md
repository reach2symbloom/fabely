# Promptbar

Manuscript prompt/composer chrome — product-specific; stays in
`src/features/promptbar/`.

Shell folder: this branch (`ft-promptbar`) holds the folder and this
README only. Each piece lands on its own `ft-promptbar-*` sub-branch as a
subfolder here, then merges back into `ft-promptbar`, mirroring how
`note-retrieved` and `chat-elements` grew.

Each piece is its own folder. Compose across them; do not duplicate
primitives into this tree.
